# お金はどこに

個人記帳工具，支援手機與電腦使用。

## 記帳功能

- 新增、編輯與刪除收入及支出。
- 自訂分類、帳戶與期初餘額。
- 按住帳戶左側把手，上下拖曳調整順序；放開自動儲存，記帳選單同步更新。
- 記錄帳戶轉帳與信用卡繳款，避免重複計入支出。
- 管理多張信用卡的結帳日與繳款日。
- 查看每月收支、分類統計與預算使用情況。
- 搜尋及篩選交易明細。

## 旅遊帳本

- 設定旅遊期間，獨立記錄旅遊支出。
- 支援台幣、日圓、韓元、美元、歐元、英鎊與澳幣。
- 每筆支出可使用不同匯率。
- 旅程結束後，按付款帳戶分別確認實際台幣金額並入帳。
- 結算後可再次調整實際金額，不會重複新增紀錄。

## 本機與雲端使用

所有人都可以使用本機記帳，無須登入。資料保存在目前裝置的瀏覽器，不會自動上傳；更換裝置或清除瀏覽器資料前，請先下載備份。

雲端同步僅供管理者核准的帳號使用。管理者可在「同步與設定」中核准或撤銷帳號；未核准或被撤銷的帳號仍可使用本機記帳。

核准帳號各自保有獨立帳本。同一個核准帳號在不同裝置登入，可接續使用自己的雲端資料。

## 備份與提醒

- 可匯出每月收支明細及完整帳本備份。
- 本機帳本與雲端帳本分開保存，可自行選擇合併匯入。
- 信用卡提醒為網站內估算，繳款日期與金額仍以銀行帳單為準。
